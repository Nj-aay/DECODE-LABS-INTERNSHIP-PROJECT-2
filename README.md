# DECODE-LABS-INTERNSHIP-PROJECT-2
Sales Performance Dashboard
A descriptive analysis of 1,200 sales transactions built in Excel, covering product revenue, order outcomes, and customer acquisition channels.
Project Overview
This project explores a retail sales dataset to answer three core business questions:
•	Which products are driving the most revenue?
•	Where are orders being lost to returns and cancellations?
•	Which acquisition channels bring in the highest-value customers?
The final output is an interactive Excel dashboard with KPI cards, charts, and slicers for filtering by product, order status, and referral source.
Dataset
•	Source: Internal sales dataset (simulated retail data)
•	Records: 1,200 orders
•	Period: 2023 – 2025
•	Fields include: Order ID, Date, Customer ID, Product, Quantity, Unit Price, Payment Method, Order Status, Referral Source, Coupon Code, Total Price

Dashboard Sections
1. Top Revenue-Generating Products
Compares total revenue and quantity sold across all product categories :Chair, Desk, Laptop, Monitor, Phone, Printer, and Tablet.
2. Return & Cancellation Trends: Breaks down order status across Delivered, Shipped, Pending, Returned, and Cancelled to identify where revenue is being lost.
3. Best Performing Acquisition Channels: Compares total revenue by referral source : Email, Facebook, Google, Instagram, and Referral  to identify which channels bring in the most valuable customers.
Tools Used
•	Microsoft Excel  data cleaning, pivot tables, dashboard layout
•	Excel Charts bar charts for product and channel analysis
•	Slicers  interactive filtering across all dashboard sections
•	Descriptive Statistics :mean, mode, standard deviation, max, via Data Analysis Toolpak
Key Findings
1.	Chair generated the highest total revenue across the period.
2.	Credit card was the highest-performing payment channel by total revenue.
